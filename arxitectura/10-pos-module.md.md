

# OpenPOS POS Module Specification

**Document:** 10-pos-module.md

**Project:** OpenPOS

**Version:** 1.0

**Status:** Approved

---

# 1. Purpose

POS Module — основное приложение кассира.

Через него выполняются:

- продажи;
- возвраты;
- обмен товаров;
- оформление заказов;
- печать чеков;
- открытие и закрытие смен;
- работа со скидками;
- поиск товаров;
- работа со штрихкодами.

POS должен работать максимально быстро.

Любая операция продажи должна занимать менее **5 секунд**.

# 4. Header

Отображает:

- название заведения;
- номер кассы;
- имя сотрудника;
- время;
- статус интернета;
- статус принтера;
- статус синхронизации.

---

# 5. Categories Panel

Отображает категории товаров.

Пример:

```
☕ Coffee

🍔 Burgers

🍕 Pizza

🥤 Drinks

🍰 Desserts
```

При выборе категории обновляется список товаров.

---

# 6. Product Grid

Каждая карточка товара содержит:

- изображение;
- название;
- цену;
- остаток (опционально);
- индикатор отсутствия товара.

Карточки должны быть большими для сенсорных экранов.

---

# 7. Cart

Каждая позиция содержит:

- название;
- количество;
- цену;
- сумму;
- комментарий;
- кнопку удаления.

---

# 8. Payment Panel

Поддерживаются способы оплаты:

- Cash
- Card
- Click
- Payme
- Uzum Bank
- Mixed Payment

---

# 9. Product Search

Поиск осуществляется по:

- названию;
- SKU;
- штрихкоду;
- QR-коду.

При сканировании товар автоматически добавляется в корзину.

---

# 10. Barcode Scanner

Поддерживаются:

- USB Scanner
- Bluetooth Scanner (Future)

Любой считанный штрихкод мгновенно ищет товар.

---

# 11. Discounts

Поддерживаются:

- фиксированная сумма;
- процент;
- скидка на товар;
- скидка на весь чек.

Все скидки логируются.

---

# 12. Order States

Заказ может иметь статусы:

```
Draft

Pending

Sent to Kitchen

Preparing

Ready

Completed

Cancelled

Returned
```

---

# 13. Restaurant Mode

Поддерживаются:

- столики;
- официанты;
- разделение счета;
- перенос заказа;
- объединение заказов;
- комментарии к блюдам.

---

# 14. Retail Mode

Поддерживаются:

- продажа по штрихкоду;
- весовой товар (Future);
- серийные номера (Future).

---

# 15. Receipt Printing

После успешной оплаты:

1. создается чек;
2. отправляется в Printer Service;
3. печатается автоматически.

Если принтер недоступен:

- чек ставится в очередь;
- повторная печать выполняется автоматически.

---

# 16. Kitchen Integration

После нажатия **Send to Kitchen**:

POS →

Backend →

WebSocket →

Kitchen Display →

Kitchen Printer

Все происходит автоматически.

---

# 17. Offline Mode

Если отсутствует интернет:

- продажи продолжаются;
- чеки печатаются;
- данные сохраняются локально;
- после восстановления соединения выполняется синхронизация.

---

# 18. Keyboard Shortcuts

```
F1 - Новый заказ

F2 - Поиск товара

F3 - Скидка

F4 - Клиент

F5 - Оплата

F6 - Печать

F7 - Отправить на кухню

ESC - Отмена

CTRL + F - Поиск
```

---

# 19. Permissions

Owner

Administrator

Cashier

имеют разные уровни доступа.

Например:

Только Administrator может удалить чек.

---

# 20. POS Settings

Настройки включают:

- принтер по умолчанию;
- налог;
- валюта;
- округление;
- язык интерфейса;
- тема (светлая/темная).

---

# 21. Performance Requirements

Открытие POS:

< 3 сек.

Добавление товара:

< 100 мс.

Оплата:

< 500 мс.

Поиск:

< 100 мс.

---

# 22. Error Handling

При любой ошибке:

- пользователь получает понятное сообщение;
- действие записывается в лог;
- система не должна завершаться аварийно.

---

# 23. Acceptance Criteria

Модуль считается готовым, если:

✅ Можно создать заказ.

✅ Можно добавить товары.

✅ Работает поиск.

✅ Работает сканер.

✅ Работает скидка.

✅ Работает оплата.

✅ Работает печать чека.

✅ Работает отправка заказа на кухню.

✅ Работает Offline Mode.
