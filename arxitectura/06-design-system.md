# OpenPOS - Design System

Version: 1.0

## Purpose

Единые правила интерфейса для всех приложений OpenPOS.

## Design Principles

-   Простота
-   Скорость работы
-   Минимум кликов
-   Высокая читаемость
-   Поддержка сенсорных экранов

## Theme

-   Light
-   Dark
-   Переключение без перезагрузки

## Colors

Primary: #2563EB Success: #16A34A Warning: #F59E0B Danger: #DC2626 Info:
#0891B2

## Typography

-   Font: Inter
-   Base: 14px
-   Buttons: 14px
-   Headings: 20-32px

## Spacing

4 / 8 / 12 / 16 / 24 / 32 px

## Components

-   Button
-   Input
-   Select
-   Table
-   Modal
-   Drawer
-   Card
-   Badge
-   Toast
-   Tabs

## POS Screen

-   Категории слева
-   Товары по центру
-   Корзина справа
-   Панель оплаты снизу

## Kitchen Cards

Статусы: - Новый (синий) - Готовится (оранжевый) - Готов (зелёный) -
Просрочен (красный)

## Icons

Использовать Lucide Icons.

## Accessibility

-   Контраст WCAG AA
-   Управление клавиатурой
-   Видимый фокус

## Responsive

Поддержка: - 10-15" POS - Desktop - Tablet

## Definition of Done

Все новые экраны обязаны использовать компоненты дизайн-системы.
