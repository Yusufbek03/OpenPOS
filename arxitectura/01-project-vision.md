# 1. Project Name

OpenPOS

> Бесплатная, современная и расширяемая POS-система для кафе,
> ресторанов, магазинов и служб доставки.

------------------------------------------------------------------------

# 2. Mission

Создать полностью бесплатную POS-систему корпоративного уровня, которая
сможет заменить дорогие решения.

Проект должен быть:

-   Open Source
-   Быстрым
-   Современным
-   Простым в использовании
-   Масштабируемым
-   Работать без платных API
-   Поддерживать работу Offline и Online

------------------------------------------------------------------------

# 5. Core Principles

## 5.1 Open Source

Проект не использует платные сервисы.

Все компоненты должны иметь бесплатные аналоги.

## 5.2 Offline First

Даже если интернет пропал:

-   продажи продолжаются;
-   чеки печатаются;
-   кухня работает;
-   после появления сети данные синхронизируются.

## 5.3 Real Time

Все изменения должны отображаться моментально.

Пример:

Кассир оформил заказ → Кухня получила заказ → Чек распечатался → Монитор
кухни обновился → Владелец увидел продажу.

## 5.4 Modular Architecture

Каждый модуль независим.

## 5.5 Multi Device

Поддерживаются:

-   Windows
-   Linux
-   Android
-   Web
