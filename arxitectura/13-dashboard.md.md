
# OpenPOS Dashboard Specification

**Document:** 13-dashboard.md

**Project:** OpenPOS

**Version:** 1.0

**Status:** Approved

---

# 1. Purpose

Dashboard — веб-приложение для управления OpenPOS.

Через Dashboard осуществляется:

- управление товарами;
- управление категориями;
- управление пользователями;
- управление заказами;
- управление складом;
- управление клиентами;
- просмотр аналитики;
- настройка системы.

---

# 2. Goals

Dashboard должен быть:

- быстрым;
- современным;
- адаптивным;
- безопасным;
- удобным для работы с большим количеством данных.

---

---

# 4. Dashboard Home

Главная страница отображает:

- продажи сегодня;
- продажи за неделю;
- продажи за месяц;
- количество заказов;
- средний чек;
- самые продаваемые товары;
- текущие активные заказы;
- статус кухни;
- статус принтеров.

---

# 5. Sales Module

Позволяет:

- просматривать продажи;
- фильтровать по датам;
- искать по номеру заказа;
- просматривать детали чека;
- делать возврат (при наличии прав).

---

# 6. Products Module

Функции:

- создание товара;
- редактирование;
- удаление (Soft Delete);
- импорт;
- экспорт;
- изменение цены;
- загрузка изображения.

---

# 7. Categories Module

Поддерживает:

- вложенные категории;
- сортировку;
- отображение иконок.

---

# 8. Orders Module

Позволяет:

- искать заказ;
- менять статус;
- повторно печатать чек;
- просматривать историю изменений.

---

# 9. Inventory Module

Поддерживает:

- приход;
- списание;
- перемещение;
- инвентаризацию;
- остатки по складам.

---

# 10. CRM Module

Для каждого клиента отображаются:

- имя;
- телефон;
- история заказов;
- сумма покупок;
- бонусы;
- скидки.

---

# 11. Employee Module

Управление:

- пользователями;
- ролями;
- правами;
- PIN-кодами;
- сменами.

---

# 12. Reports

Поддерживаются отчеты:

- ежедневный;
- еженедельный;
- месячный;
- продажи по товарам;
- продажи по категориям;
- продажи по сотрудникам;
- прибыль;
- склад.

---

# 13. Printer Management

Для каждого принтера отображаются:

- статус;
- IP;
- модель;
- очередь;
- ошибки.

Можно:

- отправить тестовую печать;
- очистить очередь;
- отключить принтер.

---

# 14. Kitchen Monitoring

Отображаются:

- новые заказы;
- готовящиеся;
- готовые;
- среднее время приготовления.

---

# 15. Settings

Настройки:

- название компании;
- логотип;
- налоги;
- валюта;
- язык;
- тема;
- номер кассы;
- параметры печати.

---

# 16. Audit Log

Журнал отображает:

- пользователя;
- действие;
- дату;
- устройство;
- IP-адрес;
- результат операции.

---

# 17. Notifications

Поддерживаются уведомления:

- закончился товар;
- принтер отключен;
- новая версия;
- ошибки синхронизации;
- новый заказ.

---

# 18. Search

Глобальный поиск позволяет искать:

- товары;
- клиентов;
- заказы;
- сотрудников.

---

# 19. Export

Поддерживается экспорт:

- PDF;
- Excel;
- CSV.

---

# 20. Security

Dashboard доступен только после авторизации.

Все страницы используют RBAC.

---

# 21. Performance

Открытие Dashboard

< 2 секунд

Поиск

< 100 мс

Загрузка таблиц

< 500 мс

---

# 22. WebSocket

Обновляются в реальном времени:

- продажи;
- новые заказы;
- кухня;
- принтеры;
- остатки.

Без обновления страницы.

---

# 23. Acceptance Criteria

Dashboard считается готовым если:

✅ Управляет товарами.

✅ Управляет заказами.

✅ Управляет сотрудниками.

✅ Управляет складом.

✅ Показывает аналитику.

✅ Работает поиск.

✅ Работает экспорт.
